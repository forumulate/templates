# Dealmark Affiliate Roundups

Affiliate roundups that stay honest: sponsored links marked and disclosed, a dense matrix, and a page that explains how the site earns money.

A COMPARE template written directly as data (no replica): a sample catalog of fictional products, comparison pages drawn from it and a `Your Brand` placeholder. Every fact carries a sample verified date; re-check and re-date them before publishing (Freshness panel in the studio).

- Every call-to-action link marked rel="sponsored nofollow" and disclosed on the page
- A dense matrix look for readers who compare on the table
- A “how we earn money” page the disclaimer links to
- No scores in the markup: ratings only from third parties
- Zero custom CSS — every detail is a theme setting
