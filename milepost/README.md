# Milepost

**An official Forumulate ROADMAP template.** Modelled on: a developer tool’s public timeline roadmap.

A product team’s public roadmap told as a timeline: lanes in the team’s own priority order, a dated rail down the page, quiet cards with no vote counts in front, and an item page that leads with the team’s answer.

Screenshots are taken from the live preview after deploy (`screenshots/desktop.png`, `screenshots/phone.png`).

## What it uses

- Preset: timeline — Now / Next / Later down one dated rail, each lane in the team’s manual priority order
- Board opens on the team’s order (`filters.defaultSort: manual`), with Top and New one click away
- Pinned items carry a pin mark; the vote control is a quiet pill at the end of the card
- Item page: the team’s answer first, then the conversation; facts and Follow on the right
- Warm paper and ink, Source Serif headings, the site’s reading column
- Zero custom CSS — every detail is a theme setting
