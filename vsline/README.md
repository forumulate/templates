# Vsline Head-to-Head

Head-to-head pages for your product against each rival: a quick verdict, the key criteria at a glance, the full matrix and the prices side by side, all drawn from one catalog.

A COMPARE template written directly as data (no replica): a sample catalog of fictional products, comparison pages drawn from it and a `Your Brand` placeholder. Every fact carries a sample verified date; re-check and re-date them before publishing (Freshness panel in the studio).

- One head-to-head page per rival, written from one catalog
- Quick verdict, key criteria at a glance, then the full matrix
- Prices made comparable per seat per month
- Every fact carries the date it was checked
- Zero custom CSS — every detail is a theme setting
