# Commonweal

**An official Forumulate About template.** Modelled on: A clean-water charity’s about page.

The mission as a pull quote, the impact in big numbers, the board and advisors, the charity’s registration and its commitments to donors.

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type and the About page's own keys (`theme.about`). Published to the space straight away.
- **The layout** — the `nonprofit` preset: which bands the generated page draws, in which order.
- **The parts** — hero, mission, impact numbers, board and advisors, commitments, timeline, testimonials, press, call to action, company facts, written through the About door (`PUT …/about`), so every value is judged by the same schema and the same reference checks as one typed in the studio.
- **The story** — one page (`About`) with the long-form prose, set as the space's home page.
- **Pictures** — 5 drawn customer wordmarks in `assets/`, copied into your library.

Replace the registration number and the figures with your own before publishing: the page states them as facts, and a charity is held to them.

The people, the numbers, the quotes and the press links are **sample content**: replace them under *About page parts* in the studio (or `fmu about set`). The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
