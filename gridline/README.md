# Gridline

**An official Forumulate custom-page template.** Modelled on: a. frontend cloud platform’s homepage

A monochrome developer-platform homepage on a hairline grid: a centred hero on a faded grid pattern, a scrolling logo marquee, a tabbed feature switcher with code, feature cards, testimonials, numbers and a two-button call to action.

## What it uses

- A landing page: the space’s address shows it, full width
- Hairline grid from section borders (no element styles)
- Centred hero on a faded grid pattern
- Logo marquee, tabbed feature switcher with code groups
- Feature cards, testimonials, numbers, two-button call to action
- Mono eyebrows over a geometric sans
- Zero custom CSS — every detail is a theme setting
- Type: Geist and Geist Mono (mirrored to our own font store, never loaded from a third party)
- Colour scheme: light

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type, motion, header and footer. Published to the space straight away.
- **The layout** — the `landing` preset.
- **1 page** — built from section bands, heroes and the section library’s blocks, published:
  - Home — the landing page itself
- **Pictures** — 10 file(s) in `assets/`, copied into your library.

“Your Brand” becomes your organization’s name wherever it appears, the wordmark included.
