# Relay Intake

**An official Forumulate template.** Modelled on: a form builder’s conversational intake page.

A one-thing-at-a-time intake form with a progress bar, branching and a thank-you per topic.

## What applying it creates

- **The look** — `bundle.json`: the `bold` contact look with a gradient backdrop, an eyebrow over the head, a sticky send button on phones.
- **The form** — page breaks (a progress bar), a scale, a country, a yes/no that opens a follow-up (`showIf`), a statement and a rating.
- **Topics** — two, each with its own thank-you (`{name}` recalled) and colour.
- **The page the copy lives on** — the intro and the facts, set as the space's home page.

Every question is the Forms model's own type — nothing here is custom code. The brand is `Your Brand`, replaced with your organization's name.
