# Stillwater Status

**An official Forumulate status page template.** Modelled on: An incident-management company’s status page.

A quiet, roomy status page that reads like a note from the team: a soft tinted banner without a glyph, sentence-case words, tinted incident cards with relative times, a subscribe card with a component picker and no legend.

## What applying it creates

- **The look** — `bundle.json`: `theme.status.look: calm` plus the keys that make this page its own (phone, subscribe, words).
- **The front page** — the bands intro, banner, active, components, history, subscribe, 720px wide.
- **Components** — 4 sample components. Every one is **manual**: nothing is probed.
- **A short history** — 3 resolved incidents dated a few days to a few weeks before you apply it, and one upcoming maintenance window. None of them notifies anybody.

The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
