# Altlist Alternatives

A directory of “best alternatives to …” pages, each with a ranked list and a line on every product, and a front page that starts with search.

A COMPARE template written directly as data (no replica): a sample catalog of fictional products, comparison pages drawn from it and a `Your Brand` placeholder. Every fact carries a sample verified date; re-check and re-date them before publishing (Freshness panel in the studio).

- One “best alternatives” page per rival, with a ranked list and a line on each
- A directory front page: search, then a grid of products
- The matrix underneath for the buyer who wants the detail
- Your own product listed like any other, never scored by you
- Zero custom CSS — every detail is a theme setting
