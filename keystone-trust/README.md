# Keystone Trust

**An official Forumulate custom-page template.** Modelled on: a. software company’s security and trust centre

A trust centre in the article layout: the page tree and an on-this-page rail, uptime and audit numbers, a wall of compliance badges, cards for each control, an FAQ and a way to reach the security team — with pages for practices, compliance, privacy, subprocessors and vulnerability reports.

## What it uses

- Article layout: page tree, on-this-page rail, breadcrumb, updated date
- Uptime and audit numbers, a wall of compliance badges
- Cards for each control, an FAQ, a contact band
- Six pages: overview, security, compliance, privacy, subprocessors, vulnerability reports
- Zero custom CSS — every detail is a theme setting
- Type: Inter and IBM Plex Mono (mirrored to our own font store, never loaded from a third party)
- Colour scheme: system (light, with a dark twin)

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type, motion, header and footer. Published to the space straight away.
- **The layout** — the `article` preset.
- **6 pages** — built from section bands, heroes and the section library’s blocks, published:
  - Trust centre — the overview, and the space’s address
  - Security practices
  - Compliance
  - Data protection
  - Subprocessors
  - Report a vulnerability
- **Pictures** — 9 file(s) in `assets/`, copied into your library.

“Your Brand” becomes your organization’s name wherever it appears, the wordmark included.
