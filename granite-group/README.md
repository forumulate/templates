# Granite Group

**An official Forumulate About template.** Modelled on: A global software company’s corporate about page.

Scale first: the numbers, the leadership, offices, awards, commitments and the legal entity, in a wide, restrained page with a rule between bands.

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type and the About page's own keys (`theme.about`). Published to the space straight away.
- **The layout** — the `enterprise` preset: which bands the generated page draws, in which order.
- **The parts** — hero, mission, numbers, leadership, offices, awards, commitments, timeline, press, press kit, company facts, written through the About door (`PUT …/about`), so every value is judged by the same schema and the same reference checks as one typed in the studio.
- **The story** — one page (`About`) with the long-form prose, set as the space's home page.
- **Pictures** — 5 drawn customer wordmarks in `assets/`, copied into your library.

The registered office and the registration numbers are placeholders — the imprint band draws whatever is filled in, so clear the ones you do not have.

The people, the numbers, the quotes and the press links are **sample content**: replace them under *About page parts* in the studio (or `fmu about set`). The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
