# Gauge Status

**An official Forumulate status page template.** Modelled on: An infrastructure monitoring company’s status page.

A dense, engineering-first status page: response time under every component's bars, square bars with three-decimal uptime, a big uptime headline, a 99.9% target and compact rows.

## What applying it creates

- **The look** — `bundle.json`: `theme.status.look: monitor` plus the keys that make this page its own (sla, subpages, title).
- **The front page** — the bands banner, active, components, metrics, history, 1040px wide.
- **Components** — 6 sample components. Every one is **manual**: nothing is probed.
- **A short history** — 3 resolved incidents dated a few days to a few weeks before you apply it, and one upcoming maintenance window. None of them notifies anybody.

The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
