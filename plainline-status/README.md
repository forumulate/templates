# Plainline Status

**An official Forumulate status page template.** Modelled on: An open-source status tool’s hosted pages.

The least a status page can be and still say everything: a ruled banner, thin ribbon bars with only the percentage beside each row, no legend, no hero, a tab icon that turns colour when something is wrong, and compact type.

## What applying it creates

- **The look** — `bundle.json`: `theme.status.look: minimal` plus the keys that make this page its own (title).
- **The front page** — the bands banner, active, components, history, 640px wide.
- **Components** — 4 sample components. Every one is **manual**: nothing is probed.
- **A short history** — 3 resolved incidents dated a few days to a few weeks before you apply it, and one upcoming maintenance window. None of them notifies anybody.

The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
