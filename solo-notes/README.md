# Solo Notes

**An official Forumulate About template.** Modelled on: An independent writer’s about page.

A narrow, personal page: the story first, the milestones newest first, where the work has been featured and how to reach the writer.

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type and the About page's own keys (`theme.about`). Published to the space straight away.
- **The layout** — the `personal` preset: which bands the generated page draws, in which order.
- **The parts** — hero, mission, values, timeline, press, awards, call to action, company facts, written through the About door (`PUT …/about`), so every value is judged by the same schema and the same reference checks as one typed in the studio.
- **The story** — one page (`About`) with the long-form prose, set as the space's home page.
- **Pictures** — 4 drawn customer wordmarks in `assets/`, copied into your library.

A personal page has no team, so the people bands stay empty. Add one if you work with others.

The people, the numbers, the quotes and the press links are **sample content**: replace them under *About page parts* in the studio (or `fmu about set`). The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
