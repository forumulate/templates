# Lantern About

**An official Forumulate About template.** Modelled on: A developer-tool startup’s about page.

The mission first, then the story, the numbers, the team and who backs it: a warm, light startup page with greyscale customer logos and quotes in a grid.

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type and the About page's own keys (`theme.about`). Published to the space straight away.
- **The layout** — the `startup` preset: which bands the generated page draws, in which order.
- **The parts** — hero, mission, values, numbers, team, leadership, investors, timeline, logos, testimonials, press, press kit, company facts, a Spanish translation, written through the About door (`PUT …/about`), so every value is judged by the same schema and the same reference checks as one typed in the studio.
- **The story** — one page (`About`) with the long-form prose, set as the space's home page.
- **Pictures** — 5 drawn customer wordmarks in `assets/`, copied into your library.

People pages are on for the team and leadership: each person with a bio has a page at `/people/<name>` and the hub `/people` lists them. Switch them off under *People pages*.

The people, the numbers, the quotes and the press links are **sample content**: replace them under *About page parts* in the studio (or `fmu about set`). The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
