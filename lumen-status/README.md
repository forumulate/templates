# Lumen Status

**An official Forumulate status page template.** Modelled on: A collaboration app’s status page.

A bold status page floating on a brand-coloured band: a centred banner that says it in one line, KPI tiles, a card per group with pill bars, an uppercase caption and the sub-pages as tabs.

## What applying it creates

- **The look** — `bundle.json`: `theme.status.look: band` plus the keys that make this page its own (subpages, title, words).
- **The front page** — the bands intro, banner, kpis, active, components, history, subscribe, 880px wide.
- **Components** — 7 sample components. Every one is **manual**: nothing is probed.
- **A short history** — 3 resolved incidents dated a few days to a few weeks before you apply it, and one upcoming maintenance window. None of them notifies anybody.

The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
