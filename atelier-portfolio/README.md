# Atelier Portfolio

**An official Forumulate template.** Modelled on: an independent designer’s portfolio site.

Selected work, a page per project, an about page.

## What applying it creates

- **The look** — the `portfolio` custom look.
- **The layout** — the `pages` preset, projects in a dropdown.

Replace the project pages with yours; the nav follows the tree. The brand is `Your Brand`, replaced with your organization's name.
