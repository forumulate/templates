# Opencore

**An official Forumulate About template.** Modelled on: An open-source infrastructure project’s about page.

The community leads: contribution links, the maintainers in a dense grid, who uses it and how it is run, in a dark developer palette.

## What applying it creates

- **The look** — `bundle.json`, a theme bundle: palette, type and the About page's own keys (`theme.about`). Published to the space straight away.
- **The layout** — the `open-source` preset: which bands the generated page draws, in which order.
- **The parts** — hero, mission, community links, maintainers, numbers, adopters, timeline, questions, call to action, company facts, written through the About door (`PUT …/about`), so every value is judged by the same schema and the same reference checks as one typed in the studio.
- **The story** — one page (`About`) with the long-form prose, set as the space's home page.
- **Pictures** — 5 drawn customer wordmarks in `assets/`, copied into your library.

The questions band uses the page’s own list (not a FAQ space): edit them under *Questions*.

The people, the numbers, the quotes and the press links are **sample content**: replace them under *About page parts* in the studio (or `fmu about set`). The brand is `Your Brand`, replaced with your organization's name. Zero custom CSS — every detail is a theme setting.
