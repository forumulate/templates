# Harbor Site

**An official Forumulate template.** Modelled on: a payroll company’s marketing site.

A multi-page site where the header nav is the page tree.

## What applying it creates

- **The look** — the `product` custom look.
- **The layout** — the `pages` preset.
- **Eight pages** — two of them nested, so the header shows dropdowns.

Every section is a block; nothing here is custom CSS. The brand is `Your Brand`, replaced with your organization's name.
